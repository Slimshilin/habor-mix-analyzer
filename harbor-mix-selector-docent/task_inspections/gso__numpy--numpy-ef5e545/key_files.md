## Gold Solution (from task.solve_sh)

Adds a real C++ ufunc for `isalpha`:

1. **`numpy/core/src/umath/string_ufuncs.cpp`** — adds `string_isalpha<rstrip, character>` template + `string_isalpha_loop` for both `npy_byte` (bytes) and `npy_ucs4` (unicode); registers a new `isalpha` ufunc with `PyUFunc_FromFuncAndData`, types `[NPY_STRING, NPY_BOOL, NPY_UNICODE, NPY_BOOL]`. Also adds helper templates `string_rstrip` / `get_length` (refactor extracted from `string_cmp`).
2. **`numpy/core/src/common/numpyos.c`** + **`numpyos.h`** — exports `NumPyOS_ascii_isalpha(char c)` (was `static int`, now `NPY_NO_EXPORT int`) so the new ufunc loop can reuse the ASCII isalpha helper.
3. **`numpy/core/defchararray.py`** — replaces `_vec_string(a, bool_, 'isalpha')` with `multiarray.isalpha(a)`.

The new ufunc handles BOTH `NPY_STRING` (bytes) and `NPY_UNICODE` dtypes via the templated loop instantiation.
