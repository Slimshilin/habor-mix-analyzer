## 2. What broke

The infinite-feeling loop is `findUForSystemAndSignal` — three calls
to `findUOneRound`, each of which sweeps through different ranges
(`[0.0, 10000.0, 1000.0]` → 10 iterations,
`[Data[1]-100, Data[1]+100, 10.0]` → 20 iterations,
`[Data[1]-10, Data[1]+10, 1.0]` → 20 iterations) of u-values, each
running a full system simulation `signal->length / signal->dt` =
≈ 1000 timesteps. Total ≈ 50000 system function calls just for
denormalization setup. If `func_system` was wired correctly and
`signal->length` was 10s with dt=0.01 that's only 1000 ticks, fast.
But if the agent left `signal->length` as integer count of samples
*and* dt=0.01, the loop becomes
`1000 seconds / 0.01 = 100000 ticks per u-sweep × 50 sweeps`, much
slower.
